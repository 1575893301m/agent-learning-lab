\# Agent Learning Lab



从零手写 Agent 的学习、实践与进化记录。



\## 学习路线



\- Task 1：ReAct 基础

\- Task 2：工具调用与多步骤任务

\- Task 3：记忆、重试与错误恢复

\- Task 4：并行、权限、规划、RAG 与反思



\## 项目原则



\- 尽量使用原生 Python

\- 不依赖 LangChain 等 Agent 框架完成核心循环

\- 每个项目必须可运行、可测试、可解释

\- 记录失败原因和修复过程
